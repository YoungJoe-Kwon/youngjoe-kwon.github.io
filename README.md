# youngjoe-kwon.github.io

GitHub Pages 사용자 사이트입니다. `https://youngjoe-kwon.github.io/` 맨 위 주소를 맡습니다.

- `app-ads.txt`: AdMob 광고 판매자 확인 파일. Google Play 스토어 설정의 웹사이트와 App Store의 마케팅 URL이 이 도메인을 가리키면 AdMob이 `https://youngjoe-kwon.github.io/app-ads.txt`를 읽습니다. 게시자 ID를 바꾸면 이 파일도 고치세요.
- `index.html`: 앱 소개와 웹 버전, 스토어, 지원, 개인정보처리방침 링크.

같은 도메인의 다른 경로는 각자 저장소가 맡습니다: `/numbersleuth/`(웹 버전), `/numbersleuth-legal/`(지원·개인정보처리방침).
